# میزبانی نسخه نمایشی در cPanel

1. در سیستم توسعه `npm ci` و سپس `npm run build` را اجرا کنید.
2. از محتوای پوشه `dist` فایل ZIP بسازید؛ `index.html` باید در ریشه ZIP باشد.
3. در File Manager مربوط به cPanel، ابتدا از فایل‌های قبلی سایت بک‌آپ بگیرید.
4. فایل‌ها را در ریشه دامنه (معمولاً `public_html`) یا پوشه ساب‌دامنه استخراج کنید.
5. SSL دامنه را فعال کنید و صفحه، تصاویر و فونت را بررسی کنید.

خروجی مسیرهای نسبی دارد و در زیرپوشه هم قابل‌نمایش است. مسیرهای این نسخه مبتنی بر anchor هستند؛ نیازی به rewrite مسیرهای SPA ندارد.

`node_modules`، سورس TypeScript و فایل‌های محیطی را در فضای عمومی هاست قرار ندهید. `dist` خروجی تولیدشده است و عمداً در گیت ثبت نمی‌شود. GitHub Actions خروجی قابل‌دانلود می‌سازد؛ انتشار خودکار یا اتصال حساب هاست در این مرحله فعال نشده است.

برای اضافه‌کردن PHP/MySQL یا سرویس Node.js در آینده، ابتدا قابلیت‌های پلن هاست مشخص شوند. سرور باید مرجع قیمت، موجودی، تخفیف و سفارش باشد. نمایش پنل فعلی جایگزین احراز هویت و مدیریت واقعی نیست.
