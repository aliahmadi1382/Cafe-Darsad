# کافه درصد

نمونه اولیه فروشگاه فارسی و راست‌به‌چپ کافه درصد، با فونت محلی **Vazirmatn** و طراحی گرم و لوکس.

## اجرا

Node.js 22 LTS پیشنهاد می‌شود.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

## امکانات نسخه نمایشی

- دسته‌بندی، جست‌وجو و مرتب‌سازی محصولات
- جزئیات محصول، سبد خرید، تغییر تعداد و حذف محصول
- علاقه‌مندی‌های ماندگار در همان مرورگر
- کد تخفیف نمونه `DARSAD10` برای تخفیف ۱۰ درصد
- فرم ثبت نظر و امتیاز محصول
- منوی کافه، داستان برند و محدوده آدرس
- پنل مدیریت نمونه برای ویرایش نام و قیمت محصولات
- طراحی موبایل، پنجره‌های محاوره‌ای با مدیریت فوکوس مرورگر و رعایت کاهش حرکت

**این سایت فروشگاه عملیاتی نیست.** سفارش یا پرداختی ثبت نمی‌شود. پنل مدیریت عمومی و نمایشی است، ورود امن ندارد و تمام تغییرات در `localStorage` همان مرورگر نگه‌داری می‌شوند. قیمت‌ها، مشخصات، منو و تصاویر نمونه‌اند؛ نظر مشتری ساختگی برای تبلیغ نمایش داده نشده است.

## ساختار

```text
src/
  App.tsx          رابط و تعاملات نسخه نمایشی
  data.ts          داده‌های اولیه محصول و منو
  main.tsx         راه‌اندازی و فونت محلی
  styles.css       سیستم بصری و نمایش واکنش‌گرا
public/images/     تصاویر محلی
docs/              تصمیم‌های طراحی، منابع، راهنمای هاست و بررسی‌ها
.github/workflows/ بررسی خودکار build
```

## انتقال به cPanel

راهنمای [نصب در cPanel](docs/CPANEL.md) را ببینید. خروجی استاتیک `dist` روی هاست معمولی Apache قابل‌میزبانی است و برای نمایش این نسخه نیاز به Node.js روی سرور ندارد. cPanel ابزار مدیریت میزبانی است؛ پنل فروشگاه واقعی باید با بک‌اند و پایگاه داده ساخته شود.

برای نسخه عملیاتی: API محصولات و موجودی، احراز هویت مدیر، پایگاه داده، مدیریت سفارش، محاسبه سمت سرور تخفیف و قیمت، درگاه پرداخت و تأیید پرداخت سمت سرور اضافه شوند. داده‌های محلی فعلی قابل‌اعتماد برای پرداخت نیستند.

آدرس ارائه‌شده: تهران، اتوبان باقری، بلوار استقلال، روبه‌روی پارک پلیس. لینک نقشه تنها محدوده را جست‌وجو می‌کند؛ نشانی دقیق، تلفن و ساعات فعالیت هنوز تأیید نشده‌اند.
